Zero-cloud sync

Local Folder Sync

Sync your video progress and Library across all your computers without creating an account, transmitting data to a developer-operated server, or running command-line scripts.

How Bynji Local Sync works

Most browser extensions require a login and send your browsing activity to remote cloud servers. Bynji takes the opposite approach: it uses the standard, browser-native File System Access API to write your Library directly to a folder on your computer that you select.

1. Browser-native

Connects through standard Chromium folder picker. No native helper binaries or terminal commands required.

2. Device isolation

Each computer writes only into its own private subfolder, preventing file conflicts and data overwrites.

3. Automatic merge

When Bynji opens or syncs, it reads the latest progress from all connected computers and merges it into your local Library.

4. Works offline

Your Library is always stored locally in your browser. Disconnected or missing folders never interrupt local playback.

Setting up multiple computers

  1. 1
    Choose your sync folder on PC 1

    Open Bynji Settings > Local Sync, click Choose sync folder, and select any local folder (for example, a folder inside your Syncthing, Dropbox, Google Drive, OneDrive, or local network share).

  2. 2
    Mirror that folder to PC 2

    Let your chosen sync service mirror that folder to your second computer as you normally would.

  3. 3
    Select the mirrored folder on PC 2

    On your second computer, open Bynji Settings > Local Sync and select the synced folder. That's it! Both computers will now synchronize progress automatically.

Compatible sync tools

Because Bynji writes standard structured files to your disk, you can use whatever file synchronization tool fits your security and privacy preferences:

  • Syncthing: 100% peer-to-peer, open-source sync with zero third-party servers.
  • Personal Cloud: Dropbox, Google Drive, Microsoft OneDrive, Proton Drive, or iCloud Drive.
  • Local Network (NAS): A Samba, NFS, or shared local network drive.
  • Manual / USB: Copy the folder between computers on a thumb drive anytime.

Using Local Sync in Brave browser

By default, the Brave browser blocks the File System Access API for privacy protection. If you use Brave, enable folder access with these quick steps:

  1. Type brave://flags into your Brave address bar.
  2. Search for File System Access API.
  3. Set the flag to Enabled and relaunch Brave.
  4. Return to Bynji Settings > Local Sync and click Choose sync folder.

Privacy and data ownership

Bynji never has access to your cloud credentials or remote storage accounts. The developer operates zero servers and cannot see your viewing history, device names, or watched titles. Your sync data remains entirely your own property and under your direct control.

Frequently Asked Questions

What happens if I disconnect my sync folder?

Nothing is lost. Your browser keeps your complete viewing history in its local database. You can re-select the folder anytime.

Can two computers overwrite each other?

No. Each computer maintains its own isolated folder. Bynji reads each device and conservatively resolves the furthest confirmed progress.

Does Local Sync cost anything?

No. Local Sync is an included, free feature of Bynji.
